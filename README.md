# Desafio — Injeção de Dependência

Desafio concluído durante o curso da **DevSuperior**, ministrado pelo professor **Nélio Alves**, com foco na aplicação de injeção de dependência em Java.

## Sobre o projeto

O objetivo do desafio é praticar a organização das dependências entre objetos, permitindo que uma classe receba os componentes necessários para executar suas responsabilidades.

Essa abordagem contribui para um código com menor acoplamento e facilita a manutenção e os testes.

## Conceitos praticados

- Injeção de dependência
- Composição de objetos
- Separação de responsabilidades
- Baixo acoplamento
- Programação orientada a objetos

## Tecnologia

- Java

## Como obter o projeto

Clone o repositório:

    git clone git@github.com:pedrohsantosdev/desafio-dev-superior.git

Acesse a pasta:

    cd desafio-dev-superior

Abra o projeto em sua IDE Java e configure o ambiente conforme os requisitos do curso.
